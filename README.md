# Quant Risk Engine

## Overview

The goal of this project is to build a quantitative risk engine from scratch in Python.

The engine is designed to:

* Download and process historical market data.
* Estimate statistical properties of asset returns.
* Simulate future asset prices using Monte Carlo methods.
* Construct and evaluate portfolios.
* Compute common risk metrics such as Value at Risk (VaR) and Conditional Value at Risk (CVaR).
* Validate simulation outputs against theoretical expectations and historical data.

This project serves both as a learning exercise in quantitative finance and as a portfolio project demonstrating skills in Python, statistics, probability, Monte Carlo simulation, and risk management.

# Current Workflow

## 1. Historical Data Collection

Historical price data is downloaded for a set of assets.

Current assets used during development:

* AAPL
* NVDA
* JPM
* SPY

From the historical prices, daily log returns are computed.

---

## 2. Parameter Estimation

For each asset:

### Drift

The annualized drift is estimated from historical returns:
$$

\mu = 252 \times \text{mean(daily returns)}

$$
### Volatility

The annualized volatility is estimated as:

$$
\sigma = \sqrt{252} \times \text{std(daily returns)}
$$

These parameters are used as inputs to the simulation engine.

---

## 3. Geometric Brownian Motion Simulation

Future asset prices are simulated using a Geometric Brownian Motion (GBM):

$$
dS_t = \mu S_t dt + \sigma S_t dW_t
$$

Thousands of Monte Carlo paths are generated for each asset.

The implementation supports:

* Multiple assets
* Vectorized simulation
* Large numbers of Monte Carlo paths

---

## 4. Correlated Asset Simulation

To model realistic portfolio behavior, correlations between assets are incorporated.

### Steps

1. Compute the historical correlation matrix.
2. Perform a Cholesky decomposition.
3. Generate independent standard normal variables.
4. Transform them into correlated shocks.

This produces simulated returns that preserve the historical dependence structure between assets.

---

## 5. Portfolio Simulation

A portfolio is constructed from the simulated assets.

For each Monte Carlo path:

1. Simulate all asset prices.
2. Compute portfolio value.
3. Store the resulting profit and loss (P&L).

The resulting distribution represents possible future portfolio outcomes.

# Validation Performed

A major focus of the project has been validating that the simulation behaves as expected.

## Mean Validation

Theoretical annualized drift estimates:

$$
\mu_{historical}
$$

were compared against:

$$
\mu_{simulated}
$$

computed from Monte Carlo simulations.

The results show close agreement, indicating that the simulation correctly reproduces the target drift.

---

## Volatility Validation

Historical volatilities were compared against simulated volatilities.

The simulated values closely match the theoretical inputs, providing evidence that the stochastic process is implemented correctly.

---

## Correlation Validation

The correlation matrix generated by the Monte Carlo simulations was compared with the historical correlation matrix.

The simulated correlations closely reproduce the target correlations, validating the Cholesky-based correlation implementation.

---

## Distribution Analysis

The distribution of terminal returns was examined using histograms.

Additional statistics computed:

* Mean
* Variance
* Skewness
* Excess Kurtosis

These metrics help evaluate departures from normality and compare historical versus simulated behavior.

# Risk Metrics Implemented

## Value at Risk (VaR)

Value at Risk estimates the maximum expected loss at a specified confidence level.

Example:

* 95% VaR
* 99% VaR

Interpretation:

> A 95% one-day VaR of $10,000 means that losses are expected to exceed $10,000 on only 5% of days.

---

## Conditional Value at Risk (CVaR)

Conditional Value at Risk (Expected Shortfall) measures the average loss beyond the VaR threshold.

$$
CVaR = E[\text{Loss} \mid \text{Loss} > VaR]
$$
        
CVaR provides information about the severity of extreme losses and is generally considered a more informative tail-risk metric than VaR alone.
